💾 Backup completo e ripristino

Un unico file .tlbackup, scritto e verificato a blocchi, con anagrafica, farmaci, integratori, assunzioni, visite, eventi, controlli, esami, documenti e tutte le foto e i PDF già caricati nell’app.

I documenti ancora presenti soltanto sul Mac devono prima essere caricati. Il backup conserva tutti i dati. Nuovo formato fino a 8 GB, singolo allegato fino a 1 GB, secondo lo spazio disponibile. I precedenti ZIP/JSON restano importabili.

Archivio .tlbackup: dati e allegati nel formato compatto consigliato. JSON .json: dati clinici e allegati incorporati in Base64, file più grande ma completo e reimportabile. Ripristina: accetta entrambi, ZIP e i vecchi JSON (i vecchi JSON conservano solo i riferimenti agli allegati online).
