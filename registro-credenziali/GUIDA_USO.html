Guida all’uso

Registro Credenziali — creato da Luca Sartori

  1. Nuova voce: inserisci il servizio, username, password ed eventuali note. Le modifiche si salvano automaticamente; attendi la conferma “Salvato”.
  2. Ricerca: cerca per servizio, username o note.
  3. Elenco completo: visualizza tutte le voci in una sola pagina, senza paginazione. Premi “Vista schede” per tornare alle schede.
  4. Modifica: premi “Apri / Modifica”. Per cancellare usa “Elimina voce” e conferma.
  5. Password: restano nascoste. Puoi mostrarle nella scheda, copiarle o renderle visibili nell’elenco con la casella dedicata.
  6. Stampa e PDF: scegli tutto il registro o i risultati della ricerca. Le password vengono incluse solo se selezioni l’opzione. Premi Crea PDF e poi Scarica PDF per salvare il file direttamente. Per stampare usa la nuova pagina dedicata oppure apri il PDF nel visualizzatore.
  7. Esporta copia: scarica un file JSON che contiene anche le password in chiaro; conservalo con cura.

La versione privata ChatGPT conserva i dati sul server con accesso riservato al proprietario. La versione GitHub è una dimostrazione con dati inventati: le prove restano solo nel browser e non si sincronizzano tra dispositivi. Cancellando i dati del browser si perdono le prove.

PIN e recupero con parola segreta

Al primo accesso scegli un PIN di 6 cifre e una parola o frase segreta di almeno 8 caratteri. Con PIN dimenticato puoi reimpostare il PIN senza perdere i dati. Maiuscole/minuscole e spazi ripetuti non fanno differenza nella parola segreta. Puoi cambiare PIN e parola dall’app. Non è necessario alcun servizio email.

Nella demo GitHub la protezione e i dati cifrati restano soltanto in questo browser: non è un account online e non c’è sincronizzazione. Usa solo dati inventati. Eliminando i dati del browser perderai sia le prove sia la configurazione; dimenticando PIN e parola segreta non potrai recuperare automaticamente il contenuto cifrato. Il limite dei tentativi è locale e non è una barriera server.

Domanda di recupero del PIN

Il PIN di 6 cifre serve per entrare. Per recuperarlo scegli una domanda (per esempio Dove sei nato?) o scrivine una personale, quindi inserisci e conferma la tua risposta segreta di almeno 8 caratteri. Domanda e risposta vengono memorizzate: con PIN dimenticato l’app mostra la domanda scelta e verifica la risposta per consentire un nuovo PIN. La risposta non viene mostrata in chiaro. Per un nome corto puoi aggiungere un dettaglio che ricordi. I dati del registro non vengono cancellati.

Se avevi già una parola segreta, il vecchio recupero continua a funzionare finché non configuri la domanda dal pulsante Configura recupero o Cambia domanda e risposta. Nella demo GitHub ogni browser ha la propria configurazione.
