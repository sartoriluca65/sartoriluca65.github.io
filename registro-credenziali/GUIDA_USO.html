Guida all’uso

Registro Credenziali — creato da Luca Sartori

  1. Nuova voce: inserisci il servizio, username, password ed eventuali note. Le modifiche si salvano automaticamente; attendi la conferma “Salvato”.
  2. Ricerca: cerca per servizio, username o note.
  3. Elenco completo: visualizza tutte le voci in una sola pagina, senza paginazione. Premi “Vista schede” per tornare alle schede.
  4. Modifica: premi “Apri / Modifica”. Per cancellare usa “Elimina voce” e conferma.
  5. Password: restano nascoste. Puoi mostrarle nella scheda, copiarle o renderle visibili nell’elenco con la casella dedicata.
  6. Stampa e PDF: scegli tutto il registro o i risultati della ricerca. Le password vengono incluse solo se selezioni l’opzione. Su Mac scegli PDF → Salva come PDF; su iPhone usa le opzioni di stampa e condivisione.
  7. Esporta copia: scarica un file JSON che contiene anche le password in chiaro; conservalo con cura.

La versione privata ChatGPT conserva i dati sul server con accesso riservato al proprietario. La versione GitHub è una dimostrazione con dati inventati: le prove restano solo nel browser e non si sincronizzano tra dispositivi. Cancellando i dati del browser si perdono le prove.
